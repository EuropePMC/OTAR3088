# SKILLs relating to the review of data and models in the OTAR3088 project

Skills in this directory are suitable for the use in directing LLM agents in the completion of tasks pertaining to review and comparison of data creation and transformer model performance.
These skills were used in the review of the CeLLaTe data _annotation guidelines_, and the comparison of fine-tuned versions of the CeLLaTeNER _transformer models_.
